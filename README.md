Vice Atlas is an offline guide to all 55 GTA VI PlayStation 5 trophies. Track earned trophies and manual counters, look up a cited unlock route, or compare the trophy targets with the game's separate 100% checklist.

## Run it

```sh
node serve.ts
```

With Node.js 22.18 or later, open http://127.0.0.1:8080 in Chrome. The app also runs on any static server rooted at `app/`. Use `MAKEFUN_OUTPUT_DIR=out node main.ts` to build the dossier.
